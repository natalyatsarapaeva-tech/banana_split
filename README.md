# Банни и Крошка: Путь через Сплит

Браузерный платформер. Статический сайт без сборки: `index.html`, код в `js/` (мир 2 — в `js/w2/`), стили в `css/`, графика и звук в `assets/`.

## Запустить локально

```bash
python3 -m http.server 8000
```

Потом открыть http://localhost:8000. Открывать `index.html` двойным кликом не стоит: музыка грузится через `fetch`, а из `file://` браузер её не отдаст.

## Сразу во второй мир

Добавьте к адресу игры `?world=2`, например http://localhost:8000/?world=2. Откроется карта мира 2
(при первом заходе — со вступлением). Прогресс мира 1 не меняется. Обычным путём мир 2 открывается после победы над Бароном.

## Публикация

GitHub Pages: Settings → Pages → Source: Deploy from a branch → нужная ветка, папка `/ (root)`.
Подойдёт и любой другой статический хостинг: достаточно выложить файлы как есть.

Прогресс игрока хранится в `localStorage` браузера.

## Проверка

```bash
node tests/smoke.js
```

```bash
node tests/w2.js
```

```bash
node tests/w2b.js
```

Все тесты на Playwright. `smoke.js` запускает каждый уровень и карты миров и проверяет, что нет ошибок. `w2.js` проверяет
механики мира 2 на уровнях 2-1, 2-2 и 2-3: воду, прилив, «Хруст», воздух, течения, прыжки по скалам, пружины, лианы, бой в лагере, босса-осьминога, лодку. `w2b.js` проверяет уровни 2-4…2-10: подъёмы, боссов, спасения, концовки и финал мира 2.
Полигон мира 2 со всеми механиками открывается из консоли браузера: `__G.startLevel('2-dev')`.
