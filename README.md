# Банни и Крошка: Путь через Сплит

Браузерный платформер. Статический сайт без сборки: `index.html`, код в `js/` (мир 2 — в `js/w2/`), стили в `css/`, графика и звук в `assets/`.

## Запустить локально

```bash
python3 -m http.server 8000
```

Потом открыть http://localhost:8000. Открывать `index.html` двойным кликом не стоит: музыка грузится через `fetch`, а из `file://` браузер её не отдаст.

## Публикация

GitHub Pages: Settings → Pages → Source: Deploy from a branch → нужная ветка, папка `/ (root)`.
Подойдёт и любой другой статический хостинг: достаточно выложить файлы как есть.

Прогресс игрока хранится в `localStorage` браузера.

## Проверка

```bash
node tests/smoke.js
```

```bash
node tests/w2.js
```

Оба теста на Playwright. `smoke.js` запускает каждый уровень и карты миров и проверяет, что нет ошибок. `w2.js` проверяет
механики мира 2 на уровнях 2-1 и 2-2: воду, прилив, «Хруст», воздух, прыжки по скалам, пружины, лианы, бой в лагере, лодку.
Полигон мира 2 со всеми механиками открывается из консоли браузера: `__G.startLevel('2-dev')`.
